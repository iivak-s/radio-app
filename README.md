# 📻 Pokhara Radios

A premium, glassmorphism-inspired web application designed to bring the heartbeat of Gandaki Province straight to your device. Listen to live, high-quality streams from the most prominent radio stations in Pokhara, Nepal, all wrapped in a stunning UI featuring breathtaking background imagery of Phewa Lake and the Annapurna range.

## ✨ Features

- **Live Streaming:** Access top Pokhara FM stations (Radio Annapurna, Big FM, Radio Barahi, etc.) in real-time.
- **Premium Aesthetic:** A highly modern, glassmorphism UI with smooth transitions, hover effects, and a dynamic layout.
- **Favorites System:** Curate your own personalized list of favorite stations for quick access.
- **Responsive Design:** Flawlessly crafted to work beautifully on both desktop monitors and mobile devices.

## 🧭 Navigation

- **Home:** Beautiful landing page with Gandaki Province imagery.
- **All Stations:** Browse the complete collection of Pokhara's finest FM radios at `/radio/all`
- **Favourites:** Quickly access the stations you love listening to the most at `/radio/favourite`

## 📦 Install

Ensure you have Node.js installed, then clone the repository and run:

```bash
npm install
```

## 🚀 Run

Start the development server:

```bash
npm run dev
```

Then, open [http://localhost:3000](http://localhost:3000) in your browser to experience the sounds of Pokhara!
